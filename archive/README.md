# Archived project files

This folder holds superseded or duplicate material retained for reference. The active project uses the V3 files at the repository root.

- legacy_v1_v2/: previous predictors, checkpoints, evaluator, timing script, training logs, and notebooks.
- duplicate_v3/: the old V3-named predictor/checkpoint, verified byte-identical to root predict.py and weights.pt.
- legacy_utilities/: exploratory scripts tied to older checkpoints or previous overlay workflows.
- duplicate_overlays/: old root-level overlay copies; these were checked byte-identical to captured/overlays/.
- scratch_assets/: unorganized intermediate masks/photos that are not part of the submission package.

The originals that were tracked before cleanup remain recoverable through Git history.
